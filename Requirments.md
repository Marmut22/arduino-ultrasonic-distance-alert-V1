## 📋 Requirements

### Hardware
* 1x Arduino Uno R3 + Kabel USB
* 1x Sensor Ultrasonik HC-SR04
* 3x LED 5mm (Merah, Kuning, Hijau)
* 3x Resistor 220Ω (atau 330Ω)
* 1x Buzzer 5V
* 1x Breadboard 400-tie point
* 12–15x Kabel Jumper Male-to-Male

### Software & Libraries
* **Arduino IDE** (v1.8.19 atau v2.x)
* **Wokwi Simulator** (Opsional, untuk pengujian virtual)
* **External Libraries:** Tidak diperlukan (menggunakan fungsi bawaan Arduino Core)
